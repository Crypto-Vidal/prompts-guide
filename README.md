# 🎯 PROMPTS Guide - Interactive How to Prompt Better

An interactive, easy-to-understand guide for learning how to ask questions more effectively and get better answers from AI.

## What is PROMPTS?

**PROMPTS** is an acronym that helps you remember the key elements to include when asking for help:

- **P** - Purpose (Say what you'll use it for)
- **R** - Role (Tell me who to act like)
- **O** - Organize Details (Give context — what, who, when, why)
- **M** - Make it Structured (Tell me how to structure it)
- **P** - Provide Examples (Show what you like)
- **T** - Tell the Style (Pick the vibe: funny, serious, etc.)
- **S** - Specify Clearly (Say exactly what you want)

**Bonus:** Edit & Retry (If it's close but not perfect, tweak it)

## Features

✅ **Interactive Cards** - Click any card to reveal "What It Means" and "Why It Helps"  
✅ **Good vs Bad Examples** - See what NOT to do and what TO do  
✅ **Role Assignment Section** - 6 different roles you can ask AI to take on  
✅ **Interactive Checklist** - Check off items as you use the framework  
✅ **Dark Mode Background** - Easy on the eyes  
✅ **Mobile Responsive** - Works on any device  

## How to Use

1. Open `prompts_guide.html` in any web browser
2. Click on any card to expand it and see examples
3. Use the PROMPTS framework when asking questions
4. Reference the checklist before submitting your prompt

## Tips

- **You don't need to follow PROMPTS in order** - use the elements that make sense for your situation
- **Include as many as you can** - the more details, the better your answer
- **The framework is flexible** - adapt it to what you need
